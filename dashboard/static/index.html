Upload data

Load records by hand when there's no API access. CSV, Excel (.xlsx) and JSON are accepted; column names are matched loosely (e.g. "GST No", "GSTN" and "gstin" all work). Every row is verified first; rows with errors are never imported. Existing rows are updated by GSTIN.
